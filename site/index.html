What happens at each level

Last Call checks the battery on every prompt and tool call. It takes about 10 milliseconds, never touches the network, and if anything goes wrong it steps aside and lets the tool run.

100%50%201050
20%
Heads up

Every agent is told the battery level and asked to finish the current step without starting long jobs: builds, full test suites, subagent fan-outs.

10%
Wrap up

Subagents and long commands are blocked. The agent is told to write .lastcall/HANDOFF.md with what was done, what is in flight, the exact next steps and the files touched, commit to a lastcall/wip branch without pushing, and stop.

5%
Last call

Every tool is blocked except writing the handoff note and git, so saving the record is the only thing left to do.

Plugged in, it all clears. No messages, no blocks. On a Mac with no battery, Last Call does nothing at all. Thresholds live in ~/.lastcall/config.

A hook, and a menu bar item

The hook does the work

A short shell script runs on PreToolUse, PostToolUse and UserPromptSubmit. It reads pmset, adds context the model sees, and denies tools with a reason when the level calls for it. It needs nothing else.

The menu bar item keeps you in the loop

It shows your battery, how many Claude processes are running and the current level, and notifies you when the level changes. Wrap up all agents now sends every session to the 10% level on demand, plugged in or not.

It is built from source on your Mac during install, so there is nothing to notarize and nothing phoning home.

Questions

Does it move my sessions to another machine?
No. It keeps the record so you can pick up anywhere. On the same Mac, run claude --resume. Anywhere else, pull the lastcall/wip branch and start a session that reads .lastcall/HANDOFF.md.
Will it break my existing hooks?
No. The installer backs up ~/.claude/settings.json and adds its three entries next to yours. If the hook cannot read the battery or its input, the tool runs as normal.
What is enforced, and what is guidance?
Blocking is enforced by the hook: at 10% subagents and long commands are refused, and at 5% every tool except the handoff note and git is refused. The model does not get a vote. Long commands at 10% are recognized by name (builds, test runs, docker and similar), so an unusual command can slip through; at 5% nothing but the handoff note and git runs. Writing the handoff and committing are instructions the agent is given; a good model follows them, but Last Call does not write or commit anything itself. If there is nothing to commit, it will not commit.
Does it push my code anywhere?
No. The commit stays on a local branch. Pushing is up to you.
Can I try it without draining my battery?
Start a session with LASTCALL_FAKE_BATTERY=8 claude, or pick Wrap up all agents now from the menu bar.
How do I remove it?
curl -fsSL https://lastagentcall.com/uninstall.sh | bash removes the hook entries, the app and ~/.lastcall, and leaves your other settings as they were.
What does it cost?
Nothing. MIT licensed.
