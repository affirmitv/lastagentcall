Your agents get a last call before the battery dies.

Last Call is a free, open source Claude Code hook for macOS. When your laptop runs low, every agent session finishes its step, writes a handoff note, commits its work to a branch, and stops. Nothing gets lost when the screen goes black.

Three levels, then silence.

Last Call reads your battery on every prompt and tool call. It takes about 10 milliseconds, makes no network calls, and if anything goes wrong it steps aside and lets the tool run.

20%

Heads up

Each agent is told the battery level and asked to finish the current step without starting long jobs like builds, full test suites, or subagent fan-outs.

10%

Wrap up

Subagents and long commands are blocked. The agent writes .lastcall/HANDOFF.md with what was done, what is in flight, the exact next steps and the files touched, then commits to a lastcall/wip branch without pushing, and stops.

5%

Last call

Every tool is blocked except writing the handoff note and git. Whatever the agent was doing, the record of it gets saved.

Plug in and it all clears. No messages, no blocks. On a desktop Mac with no battery, Last Call does nothing at all.

How it works

Two small pieces. The hook does the real work and needs nothing else.

A Claude Code hook

A short shell script runs on PreToolUse, PostToolUse and UserPromptSubmit. It reads pmset, adds context the model sees, and denies tools with a reason when the level calls for it. Thresholds live in ~/.lastcall/config.

A menu bar app

Shows your battery, how many Claude processes are running, and the current level. "Wrap up all agents now" sends every session to the 10% level on demand. It notifies you at each level and lists recent handoff notes. Built from source on your Mac during install.

Questions

What does it actually do?

It gives every running Claude Code session a warning and then a clear instruction to save its state: a handoff note in the project and a work in progress commit on its own branch. At the lowest level it blocks everything else so the save is the last thing that happens.

Does it move my sessions to another machine?

No. It keeps the record of what happened so you can pick up anywhere. On the same Mac, run claude --resume. On any machine, pull the lastcall/wip branch and start a fresh session that reads .lastcall/HANDOFF.md.

Will it break my existing hooks or slow me down?

The installer backs up ~/.claude/settings.json and merges its three entries next to yours. The hook runs in about 10 milliseconds, never touches the network, and fails open: if it cannot read the battery or the input, the tool runs as normal.

Does it push my code anywhere?

No. The commit stays on a local branch. Pushing is up to you.

Can I try it without draining my battery?

Yes. Start a session with LASTCALL_FAKE_BATTERY=8 claude and watch it wrap up. Or use "Wrap up all agents now" from the menu bar.

How do I remove it?

curl -fsSL https://lastagentcall.com/uninstall.sh | bash removes the hook entries, the app and ~/.lastcall, and leaves your other settings exactly as they were.

What does it cost?

Nothing. It is MIT licensed and the code is on GitHub.
